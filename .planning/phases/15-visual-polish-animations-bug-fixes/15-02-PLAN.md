  <action>
Create `scripts/sync-figma-tokens.mjs` (ES module, Node.js) that:

1. Reads `FIGMA_ACCESS_TOKEN` and `FIGMA_FILE_KEY` from `process.env`. If either is missing, prints a helpful error message and exits with code 1:

   ```
   Error: Missing FIGMA_ACCESS_TOKEN or FIGMA_FILE_KEY environment variables.
   Set them in your .env file or export them before running this script.
   ```

2. Fetches Figma Variables from `https://api.figma.com/v1/files/{FIGMA_FILE_KEY}/variables/local` using the native `fetch` API (Node 18+).

3. Maps Figma variable names to CSS custom property names using this convention:
   - Figma group separator `/` → CSS `-` separator
   - Figma variable `color/bg/blue-light` → CSS `--color-bg-blue-light`
   - Figma variable `font-size/xs` → CSS `--font-size-xs`
   - Figma variable `spacing/xs` → CSS `--spacing-xs`
   - Log a warning for any unmapped or unsupported variable types (skip BOOLEAN, FONT style objects)

4. Writes the output to `apps/game/assets/css/figma-tokens.generated.css` with this structure:

   ```css
   /* Auto-generated by scripts/sync-figma-tokens.mjs — DO NOT EDIT */
   /* Run: pnpm run figma:sync-tokens */
   :root {
     /* These override design-system.scss values via cascade */
     --color-bg-blue-light: #1cc6ff;
     /* ... */
   }
   ```

5. Only processes `COLOR` and `FLOAT` variable types (skip `BOOLEAN` and `STRING`).

6. Logs success summary: "Synced N tokens → apps/game/assets/css/figma-tokens.generated.css"

Create `apps/game/assets/css/figma-tokens.generated.css` as a placeholder file:

```css
/* Auto-generated by scripts/sync-figma-tokens.mjs — DO NOT EDIT */
/* Run: pnpm run figma:sync-tokens to populate from Figma */
:root {
  /* Figma token overrides will appear here after running pnpm run figma:sync-tokens */
}
```

Create the `apps/game/assets/css/` directory if it does not exist.
</action>
