# Plan: Create GamePanel Component (03-02)

## Goal

Create the `GamePanel` Vue component, which serves as a styled container for main content areas, featuring the mockup's characteristic orange/gold border, rounded corners, and inner glow.

## Plan

1.  **Create Component File:** Create `apps/game/components/layout/GamePanel.vue`.
2.  **Implement Template:**
    - Add a `<template>` section with a `<div>` element.
    - The `div` will have a `slot` to render child content.
    - Assign a class, e.g., `game-panel`, for styling.
3.  **Implement Styling:**
    - Add a `<style lang="scss">` section.
    - Define the `.game-panel` class.
    - Use the `embossed-panel` mixin (created in Phase 2) to apply the border and inner glow effects.
    - Set the `border-radius` to match the mockup (e.g., `24px` or a corresponding CSS variable).
    - Add a `background-color` that matches the panel background in the mockups.
    - Add some default padding.
4.  **Create Storybook File:**
    - Create `apps/game/components/layout/GamePanel.stories.ts`.
    - Write a story that renders the `GamePanel` inside the `GameBackground`. This will allow for visual verification of how the two components look together.
5.  **Verify in Storybook:**
    - Since I can't run storybook, I will temporarily add the component to the `default.vue` layout and verify it with a test.

## Acceptance Criteria

- The `GamePanel.vue` component and its Storybook story are created.
- The component correctly displays the orange/gold border, rounded corners, and inner glow.
- The component is viewable and verifiable, demonstrating that it can contain other content.
- The panel scales responsively with its content.
