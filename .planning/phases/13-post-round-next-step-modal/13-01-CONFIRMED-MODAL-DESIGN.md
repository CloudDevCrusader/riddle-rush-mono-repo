# Post-Round Modal - Confirmed Design

This document captures the user-approved design for the post-round decision modal.

## User Confirmation

- **Status:** Approved with modifications
- **Date:** 2026-02-27
- **Feedback:**
  ```
  User requested three options instead of two:
  1. "Play Again" - Restarts the round with the current players.
  2. "New Game" - Navigates to player selection to start a new game with different players.
  3. "View Leaderboard" - Navigates to the leaderboard.
  ```

## Final Design

- **Title:** Next Round?
- **Message:** What would you like to do next?
- **Button 1 Text:** Play Again
- **Button 1 Action:** Starts a new round with the same players.
- **Button 2 Text:** New Game
- **Button 2 Action:** Navigates to the player selection screen to start a new game.
- **Button 3 Text:** View Leaderboard
- **Button 3 Action:** Navigates to the leaderboard screen.
