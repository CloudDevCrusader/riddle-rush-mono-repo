Install focus-trap library for modal accessibility:

```bash
cd /home/cloudcrusader/projects/riddle-rush-mono-repo/apps/game
pnpm add focus-trap
```

This library provides createFocusTrap for keyboard navigation accessibility in modal dialogs. When modal is open, Tab key cycles only through interactive elements inside the modal, preventing keyboard users from accidentally interacting with background content.

**Why focus-trap:** Recommended by CONTEXT.md research as the standard solution for Vue 3 modal accessibility. Lightweight, framework-agnostic, and handles edge cases (nested traps, initial focus, return focus on close).

**Alternative considered:** VueUse useFocusTrap already available via @vueuse/nuxt. If focus-trap install fails or conflicts arise, switch to VueUse composable approach.
</action>

  <name>Create GameModal component with focus trap and variants</name>
  <files>apps/game/components/game/GameModal.vue</files>
  <action>
Create GameModal component at `apps/game/components/game/GameModal.vue`:

**Component Props:**

- `modelValue: boolean` - v-model binding for open/closed state
- `variant?: 'default' | 'danger'` (default: 'default') - Header bar color (blue or red)
- `showHeader?: boolean` (default: true) - Display colored header bar at top of modal

**Template Structure:**

- Teleport to="body" wrapper (moves modal to document body for z-index layering)
- Outer backdrop div (fixed position, full viewport, rgba backdrop)
  - Click handler: emit 'update:modelValue', false (close on backdrop click)
- Inner modal container div (centered, max-width 90vw, max-height 80vh)
  - Click handler with .stop modifier (prevent backdrop click when clicking modal content)
  - ref="modalRef" for focus trap attachment
  - Conditional header bar div (if showHeader is true)
    - Class based on variant (danger = red, default = blue)
    - Optional `header` slot for title content
  - Modal body div with default slot for content
  - Vue Transition wrapper with fade + scale animation

**Focus Trap Integration:**
Import createFocusTrap from 'focus-trap'. In script setup:

- ref modalRef for DOM element
- let focusTrap variable (not reactive)
- watch modelValue:
  - When true (modal opening): nextTick then create trap with createFocusTrap(modalRef.value, options)
    - Options: escapeDeactivates: true, clickOutsideDeactivates: false (we handle backdrop click manually)
    - Activate trap: focusTrap.activate()
  - When false (modal closing): deactivate trap if exists: focusTrap?.deactivate()
- onUnmounted: cleanup trap if still active

**Keyboard Interaction:**

- Escape key: watch for keydown event on modalRef, emit 'update:modelValue', false
- Use @keydown.esc modifier on modal container div

**Styling (scoped SCSS):**

- Backdrop: fixed inset-0, z-index 1000, background rgba(0, 0, 0, 0.55), backdrop-filter blur(4px) for slight background blur
- Modal container: position relative, z-index 1001, background var(--color-panel-bg), border-radius var(--radius-xl), overflow hidden
- Use panel-shadow mixin for lift effect
- Header bar (if shown):
  - Height: 48px, padding var(--spacing-md)
  - Default variant: background linear-gradient from var(--color-btn-blue-light) to var(--color-btn-blue-dark)
  - Danger variant: background linear-gradient from var(--color-btn-orange-light) to var(--color-btn-orange-dark) (using orange, not pure red, to match design tokens)
  - Text: font-display, font-weight-bold, color white, center-aligned
- Modal body: padding var(--spacing-xl)

**Transitions:**

- Transition name: "modal-fade"
- Enter/leave: fade opacity + scale transform
- Duration: 250ms
- Easing: ease-out for enter, ease-in for leave
- Define CSS:
  - .modal-fade-enter-from: opacity 0, transform scale(0.95)
  - .modal-fade-enter-to: opacity 1, transform scale(1)
  - .modal-fade-leave-from: opacity 1, transform scale(1)
  - .modal-fade-leave-to: opacity 0, transform scale(0.95)

**ARIA Attributes:**

- Modal container: role="dialog", aria-modal="true"
- If header slot has content: aria-labelledby="modal-title" (add id to header slot wrapper)
- Focus trap automatically handles focus management

**TypeScript:**

- Interface Props with modelValue, variant, showHeader
- defineEmits for 'update:modelValue'
- withDefaults for variant and showHeader
