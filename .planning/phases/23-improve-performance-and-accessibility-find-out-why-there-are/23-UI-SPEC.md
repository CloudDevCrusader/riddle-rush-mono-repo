---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                               |
| ----- | ----- | ----------------------------------- |
| xs    | 4px   | Icon gaps, inline padding           |
| sm    | 8px   | Compact control spacing             |
| md    | 16px  | Default control and row spacing     |
| lg    | 24px  | Section spacing inside panels       |
| xl    | 32px  | Between major performance UI blocks |
| 2xl   | 48px  | Page section breaks                 |
| 3xl   | 64px  | Full-screen layout breathing room   |

Exceptions: Touch targets keep a 44px minimum hit area for mobile controls (source: design-system.scss touch target + phase accessibility intent).

---

## Color

| Role            | Value   | Usage                                                                |
| --------------- | ------- | -------------------------------------------------------------------- |
| Dominant (60%)  | #0B7AD6 | Main backgrounds and full-screen performance/audit surfaces          |
| Secondary (30%) | #FFF3D4 | Cards, modal content panels, asset tables, diagnostics rows          |
| Accent (10%)    | #FFD54F | Run-audit CTA, lighthouse score chips, optimized-asset success count |
| Destructive     | #FF5B5B | Delete/remove-unused-assets action and irreversible confirmations    |

Accent reserved for: primary action button, key KPI badges (scores/savings), active filter chips, and progress indicators only.

## Copywriting Contract

| Element                  | Copy                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| Primary CTA              | Run Performance Audit                                                                         |
| Empty state heading      | No broken images found                                                                        |
| Empty state body         | All referenced assets loaded successfully. Re-run audit after deploy.                         |
| Error state              | Some production assets failed to load. Check file paths and asset naming, then retry audit.   |
| Destructive confirmation | Remove unused assets: This deletes unreferenced files from production build output. Continue? |
