Create `apps/game/components/game/GameDisplay.vue` as a presentational text display component.

**Script section:**

- TypeScript interface with props: `size` ('sm' | 'md' | 'lg' | 'xl', default 'md'), `glow` (boolean, default true), `tag` ('span' | 'div' | 'p' | 'h1' | 'h2' | 'h3', default 'span') for semantic flexibility
- Computed `displayClasses` generating BEM classes: `game-display`, `game-display--{size}`, conditional `game-display--glow`

**Template section:**

- Use `<component :is="tag">` to render dynamic semantic element
- Apply `:class="displayClasses"` on the dynamic component
- Single `<slot />` for content

**Style section (scoped, lang="scss"):**

- Import: `@use 'assets/scss/effects/shadows' as *;`
- Base `.game-display` styles:
  - `font-family: var(--font-display)`
  - `font-weight: var(--font-weight-bold)`
  - `color: var(--color-text-yellow)`
  - `line-height: 1.1`
  - `text-align: center`
- Size variants:
  - `--sm`: `font-size: var(--font-size-lg)` (for small counters)
  - `--md`: `font-size: var(--font-size-2xl)` (for score displays)
  - `--lg`: `font-size: var(--font-size-3xl)` (for category letters)
  - `--xl`: `font-size: var(--font-size-display)` (for hero letter display)
- Glow modifier `--glow`: apply `@include text-glow()` from the shadows effects file. This uses the default params ($color: var(--color-text-yellow), $soft-color: var(--color-border-gold)) which matches the mockup gold glow.
- No GPU acceleration hints (will-change/translateZ) since this is static text -- add only if animations are introduced later per research recommendation.

**Contrast note:**

- Yellow text (#ffd54f via --color-text-yellow) on dark blue (#0a4cc7 via --color-bg-blue-dark) achieves approximately 7.2:1 contrast ratio, well above WCAG AA 4.5:1 requirement.
- The text-glow mixin adds visual enhancement but contrast is measured against the actual background color, not the glow.

**Important:**

- Do NOT add `will-change` or `transform: translateZ(0)` -- research explicitly recommends against GPU hints for static text to avoid memory issues on mobile
- The `tag` prop enables proper semantic HTML -- use h1/h2 for headings, span for inline, div for block display
