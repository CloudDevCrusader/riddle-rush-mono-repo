Create `apps/game/components/game/GameButton.vue` following the existing Base/Button.vue pattern but with game-specific styling.

**Script section:**

- TypeScript interface with props: `variant` ('primary' | 'secondary' | 'warning', default 'primary'), `size` ('sm' | 'md' | 'lg', default 'md'), `type` ('button' | 'submit' | 'reset', default 'button'), `disabled` (boolean, default false), `loading` (boolean, default false), `fullWidth` (boolean, default false)
- `defineEmits` for `click: [event: MouseEvent]`
- Computed `buttonClasses` generating BEM classes: `game-button`, `game-button--{variant}`, `game-button--{size}`, conditional `game-button--disabled`, `game-button--loading`, `game-button--full-width`
- `handleClick` that guards against disabled/loading state before emitting

**Template section:**

- Semantic `<button>` element with `:class`, `:type`, `:disabled`, `:aria-busy="loading"`
- `<span v-if="loading" class="game-button__spinner" />` and `<slot v-else />`

**Style section (scoped, lang="scss"):**

- Import effects: `@use 'assets/scss/effects/glossy' as *;`
- Base `.game-button` styles: `display: inline-flex`, `align-items: center`, `justify-content: center`, `gap: var(--spacing-sm)`, `font-family: var(--font-display)`, `font-weight: var(--font-weight-bold)`, `border-radius: var(--radius-lg)`, `border: 3px solid rgba(255, 255, 255, 0.35)`, `cursor: pointer`, `transition: all var(--transition-fast)`, `color: var(--color-text-dark)`, `text-shadow: 0 1px 0 rgba(255, 255, 255, 0.35)`, `-webkit-tap-highlight-color: transparent`, `user-select: none`, `position: relative`
- Size variants:
  - `--sm`: padding `var(--spacing-sm) var(--spacing-md)`, font-size `var(--font-size-sm)`, min-height 40px
  - `--md`: padding `var(--spacing-md) var(--spacing-lg)`, font-size `var(--font-size-md)`, min-height 52px
  - `--lg`: padding `var(--spacing-lg) var(--spacing-xl)`, font-size `var(--font-size-lg)`, min-height 64px
- Color variants using `@include glossy-button(...)`:
  - `--primary`: $light: `var(--color-btn-green-light)`, $dark: `var(--color-btn-green-dark)`, $shadow: `var(--color-btn-green-shadow)`
  - `--secondary`: $light: `var(--color-btn-blue-light)`, $dark: `var(--color-btn-blue-dark)`, $shadow: `var(--color-btn-blue-shadow)`
  - `--warning`: $light: `var(--color-btn-orange-light)`, $dark: `var(--color-btn-orange-dark)`, $shadow: `var(--color-btn-orange-shadow)`
- Active state `&:active:not(:disabled)`: `transform: translateY(4px)`, override box-shadow to reduce the bottom offset by 4px (from 10px to 6px in the shadow portion)
- Hover state `&:hover:not(:disabled)`: subtle brightness increase via `filter: brightness(1.05)`
- Disabled state `--disabled`: `opacity: 0.5`, `cursor: not-allowed`
- Focus visible `&:focus-visible`: `outline: 3px solid rgba(255, 255, 255, 0.8)`, `outline-offset: 4px`
- Full width `--full-width`: `width: 100%`
- Spinner `__spinner`: copy pattern from Base/Button.vue spinner styles (inline-block, 16px, border animation)
- White text for dark button backgrounds: `color: white` (override the dark text default since all three game button variants have dark gradient backgrounds)

**Important notes:**

- Do NOT use `pointer-events: none` on disabled -- use `:disabled` pseudo-class with `cursor: not-allowed` so screen readers still detect the element
- The glossy-button mixin already handles `position: relative`, `overflow: hidden`, and the `::before` highlight pseudo-element, so don't duplicate those
- Use `lang="scss"` on the style block, not plain CSS
