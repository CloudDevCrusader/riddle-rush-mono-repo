**Create `scripts/sync-figma-tokens.mjs`:**

Node.js ESM script that:

1. Reads `FIGMA_ACCESS_TOKEN` and `FIGMA_FILE_KEY` from environment variables
2. If either is missing, logs a helpful warning message and exits with code 0 (not error — this is expected during dev)
3. Calls Figma Variables REST API: `GET /v1/files/{fileKey}/variables/local` with Bearer token auth
4. Maps Figma variable names to CSS custom property names using this convention:
   - Figma `color/bg/blue-light` -> `--color-bg-blue-light`
   - Figma `color/btn/green-light` -> `--color-btn-green-light`
   - Figma `font-size/md` -> `--font-size-md`
   - Figma `spacing/sm` -> `--spacing-sm`
   - General rule: replace `/` with `-`, prepend `--`
5. For any Figma variable that doesn't map to a known CSS property, log a warning (don't error)
6. Writes output to `apps/game/assets/css/figma-tokens.generated.css` with format:

```css
/* Auto-generated by scripts/sync-figma-tokens.mjs -- DO NOT EDIT */
/* Last synced: {ISO date} */
/* Source: Figma file {fileKey} */
:root {
  /* These override design-system.scss values via cascade */
  --color-bg-blue-light: #value;
  /* ... */
}
```

7. Logs summary: "Synced N tokens, M warnings"

**Create placeholder `apps/game/assets/css/figma-tokens.generated.css`:**

```css
/* Auto-generated by scripts/sync-figma-tokens.mjs -- DO NOT EDIT */
/* Run: pnpm run figma:sync-tokens */
/* No tokens synced yet — this file is a placeholder */
:root {
  /* Figma token overrides will appear here after running sync */
}
```

This placeholder ensures the CSS file exists for nuxt.config.ts to reference without errors.
</action>
