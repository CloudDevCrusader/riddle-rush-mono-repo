<task type="auto">
  <name>Task 2: Create UnoCSS Configuration</name>
  <files>apps/game/uno.config.ts</files>
  <action>
Create `apps/game/uno.config.ts` with this exact configuration:

```typescript
import { defineConfig, presetWind, transformerDirectives, transformerVariantGroup } from 'unocss'

export default defineConfig({
  // Tailwind-compatible utilities
  presets: [presetWind()],

  // Enable @apply and variant groups in Vue SFC styles
  transformers: [transformerDirectives(), transformerVariantGroup()],

  // Extend theme to consume SCSS CSS custom properties
  theme: {
    // Map spacing utilities to design-system.scss tokens
    spacing: {
      xs: 'var(--spacing-xs)',
      sm: 'var(--spacing-sm)',
      md: 'var(--spacing-md)',
      lg: 'var(--spacing-lg)',
      xl: 'var(--spacing-xl)',
      '2xl': 'var(--spacing-2xl)',
      '3xl': 'var(--spacing-3xl)',
    },

    // Map border radius to design tokens
    borderRadius: {
      sm: 'var(--radius-sm)',
      md: 'var(--radius-md)',
      lg: 'var(--radius-lg)',
      xl: 'var(--radius-xl)',
      full: 'var(--radius-full)',
    },

    // Container settings for game layout
    container: {
      center: true,
      padding: {
        DEFAULT: '1rem',
        sm: '1.5rem',
        lg: '2rem',
      },
    },
  },

  // Safelist classes that may be used dynamically
  safelist: [
    'flex',
    'flex-col',
    'items-center',
    'justify-center',
    'gap-md',
    'gap-lg',
    'p-md',
    'p-lg',
    'px-md',
    'py-md',
  ],

  // Content paths for scanning
  content: {
    pipeline: {
      include: [/\.vue$/, /\.ts$/, /\.tsx$/],
    },
  },
})
```

Key decisions:

- Only preset-wind (Tailwind utilities) - no web fonts preset (use existing @nuxtjs/fontaine)
- Spacing/radius consume CSS variables from design-system.scss for single source of truth
- Transformers enable @apply directive in Vue SFC for hybrid styling
- Safelist includes commonly used utility combinations

<task type="auto">
  <name>Task 3: Register UnoCSS Module in Nuxt Config</name>
  <files>apps/game/nuxt.config.ts</files>
  <action>
Update `apps/game/nuxt.config.ts` to register UnoCSS module.

1. Add `@unocss/nuxt` to the modules array AFTER `@pinia/nuxt` and BEFORE `@vite-pwa/nuxt`:

```typescript
modules: [
  '@pinia/nuxt',
  '@nuxtjs/i18n',
  '@unocss/nuxt',  // Add here - after Pinia/i18n, before PWA
  '@vite-pwa/nuxt',
  // ... rest
],
```

2. The CSS load order is critical for specificity. The existing `css` array already loads design-system.scss first:

```typescript
css: ['~/assets/scss/design-system.scss'],
```

UnoCSS auto-injects its styles AFTER the css array, so utilities will have higher specificity than base styles. This is the correct order.

Do NOT add `uno.css` or `@unocss/reset` to the css array - @unocss/nuxt handles this automatically.

Do NOT modify the existing design-system.scss import.
</action>
