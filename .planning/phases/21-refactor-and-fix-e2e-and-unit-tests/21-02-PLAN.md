# Composable purity analysis from code review

## useAnalytics (STATEFUL)

- Uses useNuxtApp(), useRuntimeConfig() - Nuxt composables
- Has computed values using Vue reactivity
- Depends on import.meta.client environment check
- Global \$gtag from Nuxt plugin
- Requires comprehensive mocking of Nuxt environment

## useSessionManager (PURE)

- Only uses type imports from @riddle-rush/types/game
- Only uses generateUUID from utils/uuid
- Functions are deterministic: input -> output
- Mocking needs only generateUUID (or use existing factory functions)

## usePersistence (STATEFUL)

- Wraps useIndexedDB() and useLogger() calls
- All functions are async with try/catch error handling
- Functions: loadSessionFromDB, loadHistoryFromDB, saveSessionToDB, saveHistoryToDB, loadSessionById
- Requires mocking of useIndexedDB and useLogger

## useGameLifecycle (MIXED)

- Pure functions: createAttempt, buildRoundResult (deterministic input/output)
- Async wrapper: updateStatisticsForSession (calls useStatistics)
- Requires mocking of useStatistics and useLogger
