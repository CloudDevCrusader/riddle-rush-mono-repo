```vue
            </div>
          </button>

          <!-- German option -->
          <button
            class="language-row"
            :class="{ selected: selectedLocale === 'de' }"

            </div>
          </button>
        </div>
      </GamePanel>

      <!-- OK Button -->
      <GameButton variant="primary" size="lg" @click="confirmSelection"> OK </GameButton>
    </div>
  </GameBackground>
</template>
```

**Script changes:**

1. Keep existing imports: usePageSetup, useI18n, useGameState, useRoute, useRouter
2. `selectedLocale` ref: Initialize from current locale.value (NOT applied yet)
3. `selectLanguage(lang)`: Update selectedLocale ref only (staging selection)
4. `confirmSelection()`:
   - Save to settingsStore.setLanguage(selectedLocale)
   - Set locale via setLocale(selectedLocale)
   - Navigate home or back (router.back() or router.push('/'))
   - Optionally reload for full translation update (keep existing reload logic)
5. `goBack()`: Navigate without applying changes
6. Remove: References to PNG assets (Eng Flag.png, German Flag.png, mark.png, Language button.png, back.png, OK.png, LANGUAGE.png)

**Style changes:**

Remove all image-based styles and add CSS-only styling:

1. `.language-page`:
   - Flex column, centered
   - Full height with padding
   - Gap between sections

2. `.back-btn`:
   - Position absolute top-left
   - Round/pill shape with orange background
   - White arrow icon
   - Touch-friendly size (44x44 minimum)

3. `.language-panel`:
   - Additional padding inside GamePanel
   - Full width, max-width constraint

4. `.language-options`:
   - Flex column
   - Gap between rows

5. `.language-row`:
   - Flex row with space-between
   - Background: Light cream/tan gradient (wooden button look)
   - Border: 3px solid gold/orange
   - Border-radius: 12-16px
   - Padding for touch targets
   - Min-height: 70px
   - Active state: Scale down slightly
   - Selected state: Brighter border, subtle highlight

6. `.flag-container`:
   - Fixed width square (50-60px)
   - White/cream background
   - Rounded corners
   - Border for definition
   - Overflow hidden

7. `.flag-emoji`:
   - Large font-size (2rem+)
   - Centered in container

8. `.language-name`:
   - Flex: 1
   - Font-family: var(--font-display)
   - Brown/dark text color
   - Bold weight
   - Text aligned left

9. `.checkbox`:
   - Fixed width (32-40px)
   - Height same as width
   - Border: 2px solid dark color
   - Border-radius: 4-6px
   - Background: white when empty, green when checked
   - Flex center for checkmark

10. `.checkmark`:
    - Color: white on green background (or dark green on light green)
    - Font-size: 1.5rem
    - Animation: scale-in when appearing

**Animations:**

1. `checkmark-enter`: Scale from 0.5 to 1, opacity 0 to 1
2. Row highlight: Brief brightness flash when selected

**Accessibility:**

- Buttons have proper focus states
- High contrast between text and background
- Emoji flags have implicit meaning (country flags)

**Design consistency with CONTEXT.md:**

- Emoji flags (🇬🇧 🇩🇪) - consistent with simple approach
- Checkmark icon inside square (not solid green square)
- Empty checkbox outline when unselected
- Selection applies on OK press (not immediately)
- Design expandable for more languages
