  <action>
Create a reusable GameSlider component for volume controls with custom game styling:

**Props:**

- `modelValue: number` (0-100, required)
- `min?: number` (default: 0)
- `max?: number` (default: 100)
- `icon?: string` (emoji icon, e.g., '🔊')
- `mutedIcon?: string` (emoji icon for muted state, e.g., '🔇')
- `label?: string` (optional label text)

**Emits:**

- `update:modelValue` - v-model binding
- `change` - fires when user finishes adjusting (mouseup/touchend)

**Template structure:**

```vue
<div class="game-slider">
  <div class="game-slider__icon">{{ displayIcon }}</div>
<div class="game-slider__track-container" @click="handleTrackClick" @mousedown="startDrag">
    <div class="game-slider__track">
      <div class="game-slider__fill" :style="fillStyle" />
    </div>
<div class="game-slider__thumb" :style="thumbStyle" />

<input type="range" class="game-slider__input" />
```

**Script logic:**

1. Compute `displayIcon` - show mutedIcon when value is 0, otherwise show icon
2. Compute `fillStyle` - width percentage based on value
3. Compute `thumbStyle` - left position based on value
4. `handleTrackClick(event)` - calculate position from click, emit new value
5. `startDrag()` - add mousemove/touchmove listeners for smooth dragging
6. `endDrag()` - remove listeners, emit 'change' event
7. Support both mouse and touch events for mobile

**Styling (SCSS):**

1. **Track:** Horizontal bar with rounded ends
   - Height: 16-20px
   - Background: Brown/tan gradient (unfilled portion matches mockup wooden barrel look)
   - Border-radius: 10px
   - Inner shadow for depth

2. **Fill:** Green portion up to thumb position
   - Background: Linear gradient from bright green (#7ed321) to darker green (#5fc423)
   - Rounded left end

3. **Thumb:** Circular peg/knob
   - Size: 28-32px diameter
   - Background: Gradient (tan/orange matching wooden peg look)
   - Border: 3px solid with gold/orange color
   - Box-shadow for depth
   - Positioned with transform: translateX(-50%)

4. **Hidden input:** Overlay for accessibility
   - Opacity: 0 but full width/height
   - Provides native range input accessibility
   - Connect to v-model for keyboard support

5. **Icon container:**
   - Fixed width for alignment
   - Font-size for emoji visibility
   - Shows muted icon when value is 0

**Design consistency with mockup:**

- Track has wooden barrel/log appearance via brown gradient
- Fill is vibrant green to show progress
- Thumb resembles wooden peg via tan/orange gradients
- Overall matches game's playful, wooden aesthetic

**Responsive sizing:**

- Use clamp() for track height and thumb size
- Icon size scales with viewport

          muted-icon="🔇"
          label="Music"
          @change="handleMusicChange"

    </div>
