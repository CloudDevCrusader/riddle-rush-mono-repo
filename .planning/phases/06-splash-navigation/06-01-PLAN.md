  <action>
Create new splash.vue page in apps/game/pages/ directory with:

**Template structure:**

1. GameBackground component for blue radial gradient
2. Main container with centered layout
3. GameHeader component with color="gold" for "RIDDLE RUSH" title
4. Loading section positioned at bottom with:
   - Progress bar track (white/transparent border, rounded)
   - Progress bar fill (orange gradient, animated via :style width binding)
   - "LOADING...." text below bar

**Script logic:**

1. Import useNavigation composable (goHome method)
2. Create progress ref starting at 0
3. onMounted lifecycle:
   - Start interval updating progress every 50ms
   - Increment progress to reach 100% in 2000ms (2s total)
   - When progress >= 100, clear interval and call goHome() after 300ms delay
4. Tap-to-skip functionality:
   - canSkip ref (false initially)
   - setTimeout to set canSkip=true after 1000ms
   - handleSkip method calls goHome() if canSkip is true
   - Add @click="handleSkip" to splash-page div

**Styling (scoped SCSS):**

1. .splash-page: Full viewport height (min-height: 100vh, 100dvh), flex center, relative positioning
2. .splash-container: Relative z-index 2, flex column, centered, gap var(--spacing-3xl), full width, padding var(--spacing-2xl)
3. .splash-title: Override GameHeader size with :deep(.game-header\_\_title) { font-size: var(--font-size-display) }
4. .splash-loading: Absolute positioning at bottom (var(--spacing-3xl) from bottom), flex column, centered, gap var(--spacing-md)
5. .loading-bar: Full width, max-width 500px
   - \_\_track: Height 12px, rounded (var(--radius-full)), border 2px solid rgba(255,255,255,0.4), overflow hidden, background rgba(255,255,255,0.2)
   - \_\_fill: Height 100%, orange gradient (--color-btn-orange-light to --color-btn-orange-dark), rounded, transition width 0.1s linear
6. .loading-text: Display font, lg size, bold, white color, embossed shadow, letter-spacing 2px
7. Mobile responsive: Reduce bottom spacing and side margins at max-width 768px

**Why these specific choices:**

- GameHeader for title: Existing component already provides 3D text effect matching mockup
- CSS transition on width: Smoother than discrete JS updates, GPU accelerated
- 2s loading duration: Long enough for branding visibility, short enough to not annoy
- Tap-to-skip after 1s: Allows users to skip after seeing branding once
- 300ms navigation delay: Matches project's navigation timing pattern
- Orange gradient for progress bar: Matches mockup color scheme
- Use existing CSS variables: Consistent with design system (spacing, colors, radius, fonts)
