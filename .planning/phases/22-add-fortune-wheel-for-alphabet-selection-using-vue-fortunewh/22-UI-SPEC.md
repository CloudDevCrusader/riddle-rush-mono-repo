## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                        |
| ----- | ----- | -------------------------------------------- |
| xs    | 4px   | Tight icon/text gaps inside wheel labels     |
| sm    | 8px   | Compact spacing between label and value      |
| md    | 16px  | Default spacing between wheel controls       |
| lg    | 24px  | Section padding around wheel panel           |
| xl    | 32px  | Gap between wheel and primary action area    |
| 2xl   | 48px  | Major vertical spacing on round-start screen |
| 3xl   | 64px  | Page-level top/bottom separation             |

Exceptions: interactive touch targets must be **min 44px** (source: existing touch-target convention in `design-system.scss`)

## Color

| --------------- | --------- | -------------------------------------------------------------------------------------------- |
| Dominant (60%)  | `#0B7AD6` | Round-start background and primary wheel container surface                                   |

| Accent (10%)    | `#FFD54F` | Selection glow, active slice highlight, selected letter emphasis, primary spin CTA highlight |
