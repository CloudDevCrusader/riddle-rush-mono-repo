  <files>.github/workflows/deploy-dev.yml</files>
  <action>
Read the full deploy-dev.yml file first.

Make three targeted changes:

**Change 1 — Fix quality gate (line ~64):**
Change `if: always()` to `if: success()` on the deploy job. This ensures the deploy job only runs when the quality-checks job succeeds.

**Change 2 — Remove Trunk Check from quality-checks job:**
Delete the entire Trunk Check step from the quality-checks job:

```yaml
- name: Trunk Check
  uses: trunk-io/trunk-action@v1
  with:
    check-mode: all
```

This step is not documented in CLAUDE.md or AGENTS.md and creates an undocumented third-party service dependency.

**Change 3 — Add pnpm store cache to deploy job:**
In the deploy job steps, after `Setup Node.js` and before `Install dependencies`, add:

```yaml
- name: Cache pnpm store
  uses: actions/cache@v4
  with:
    path: ~/.pnpm-store
    key: ${{ runner.os }}-pnpm-store-${{ hashFiles('**/pnpm-lock.yaml') }}
    restore-keys: |
      ${{ runner.os }}-pnpm-store-
```

After these three edits, the quality-checks job should run: checkout, pnpm setup, node setup, install deps, typecheck, lint, unit tests. The deploy job should run: checkout, pnpm setup, node setup, pnpm cache, install deps, configure AWS, deploy script, summary.
</action>
