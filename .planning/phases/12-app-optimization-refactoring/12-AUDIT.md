## Audit Checklist (Per Page)

**Theming:**

- [ ] Uses CSS variables from design system
- [ ] Primary/secondary/accent colors consistent
- [ ] Dark mode support (if applicable)

**Spacing:**

- [ ] Consistent padding/margins (4px, 8px, 16px, 24px, 32px grid)
- [ ] Adequate white space between elements
- [ ] No layout overflow or clipping

**Typography:**

- [ ] Font sizes follow scale (12px, 14px, 16px, 20px, 24px, 32px)
- [ ] Line heights readable (1.5 for body, 1.2 for headings)
- [ ] Font weights consistent (400 for body, 600 for headings)

**Responsive Behavior:**

- [ ] Mobile (320px - 767px): Single column, touch-friendly targets
- [ ] Tablet (768px - 1023px): Optimized layout
- [ ] Desktop (1024px+): Max-width container, centered content

**Accessibility:**

- [ ] Color contrast ratios meet WCAG AA (4.5:1 for text)
- [ ] Interactive elements have focus states
- [ ] Buttons/inputs have accessible labels
