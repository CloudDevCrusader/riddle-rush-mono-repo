Split the monolithic `vueGameStore.ts` into focused hooks. CRITICAL: Use the subscribe+version reactivity pattern (NOT the snapshot pattern that the old vueGameStore.ts used, which is NOT reactive in Zustand v5 + Vue).

Each hook follows this pattern:

```typescript
import { computed, ref, onScopeDispose } from 'vue'
import { gameStore } from '../gameStore'

export function useGameSession() {
  const version = ref(0)
  const unsubscribe = gameStore.subscribe(() => {
    version.value++
  })
  onScopeDispose(() => unsubscribe())

  return {
    // State/getters: wrap in computed() with version.value dependency
    currentSession: computed(() => {
      void version.value
      return gameStore.getState().currentSession
    }),
    // Actions: direct references from getState() -- stable, no computed needed
    startNewGame: gameStore.getState().startNewGame,
  }
}
```

Hook splitting (based on what consumers actually need from research of useGameState.ts, useGameActions.ts, DebugPanel.vue, app.vue):

- Getters: hasActiveSession, isGameCompleted, gameStatus, currentRound, currentCategory, currentLetter, players, currentPlayerTurn, allPlayersSubmitted, leaderboard
- Actions: resumeOrStartNewGame, startNewGame, endGame, completeGame, abandonGame, clearSession, loadFromDB, saveSessionToDB, saveHistoryToDB, loadSessionById, setupPlayers, generateLetter

**useCategories.ts** -- category management:

- State: categories, categoriesLoaded, categoriesLoading, displayedCategoryCount, categoryLoadError
- Getters: displayedCategories, hasMoreCategories
- Actions: fetchCategories, loadMoreCategories, resetDisplayedCategories, getCategoryById, getRandomCategory, categoryEmoji

**usePlayerActions.ts** -- player operations:

- Actions: submitPlayerAnswer, assignPlayerScore, updatePlayerAvatar, completeRound, startNextRound, resetPlayerSubmissions, getPlayerById

**useInstallPrompt.ts** -- PWA install:
