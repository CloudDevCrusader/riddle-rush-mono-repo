## Objective

Create the GameHeader component with 3D text effects and multiple color variants, and the GameScrollList component with scrollable content and rank display (crowns for 1-3, numbered badges for 4-6).

## Context

From 05-CONTEXT.md:

- GameHeader: Full header bar with left/right slots, 5 color variants (white, gold, green, blue, orange), transparent background
- GameScrollList: Generic list with slot content, custom scrollbars, showRanks prop for crown/badge display

From 05-RESEARCH.md:

- Multi-layer text-shadow (3-5 layers) for 3D text effects
- Inline SVG for rank icons
- CSS overflow-y with custom scrollbar styling

## Tasks

<task id="1" type="implement">
<title>Create GameHeader component</title>
<description>
Create components/game/GameHeader.vue with:

**Props:**

- `color`: 'white' | 'gold' | 'green' | 'blue' | 'orange' (default: 'white')

**Slots:**

- `left`: Optional back button slot
- `default`: Title text
- `right`: Optional right content slot

**Structure:**

```vue
<header class="game-header">
  <div class="game-header__left"><slot name="left" /></div>
  <h1 class="game-header__title game-header__title--{color}"><slot /></h1>
  <div class="game-header__right"><slot name="right" /></div>
</header>
```

**Styling:**

- Flexbox layout with space-between
- Title centered with flex: 1
- Left/right slots: min-width 44px (touch target)
- Font: var(--font-display), var(--font-size-3xl), var(--font-weight-bold)
- Transparent background

**3D Text Effect (per color variant):**
Create SCSS mixin in assets/scss/effects/\_text-3d.scss:

```scss
@mixin text-3d($color, $highlight, $shadow, $glow) {
  color: $color;
  text-shadow:
    0 1px 0 $highlight,
    0 2px 2px rgba(0, 0, 0, 0.15),
    0 4px 4px rgba(0, 0, 0, 0.2),
    0 8px 12px $shadow,
    0 0 20px $glow;
}
```

Apply variants:

- white: white text, white highlight/glow, dark shadow
- gold: var(--color-text-yellow), gold glow
- green: var(--color-btn-green-light), green glow
- blue: var(--color-btn-blue-light), blue glow
- orange: var(--color-btn-orange-light), orange glow

<task id="2" type="implement">
<title>Create GameScrollList component</title>
<description>
Create components/game/GameScrollList.vue with:

**Props:**

- `showRanks`: boolean (default: false)
- `maxHeight`: string (default: '400px')

**Slots:**

- `default`: Scoped slot with { item, index }
- `rank`: Scoped slot with { rank } for custom rank display

**Built-in Rank Display (when showRanks=true and no rank slot):**

- Ranks 1-3: Inline SVG crown icons (gold, silver, bronze)
- Ranks 4-6: Numbered circle badges

**Crown SVG (inline):**

```html
<svg viewBox="0 0 24 24" class="crown-icon crown-icon--{color}">
  <path d="M12 2L15 9L22 8L19 15H5L2 8L9 9L12 2Z" />
  <rect x="4" y="15" width="16" height="4" rx="1" />
</svg>
```

**Scrollbar Styling:**

```scss
scrollbar-width: thin;
scrollbar-color: var(--color-btn-blue-dark) rgba(255, 255, 255, 0.2);

&::-webkit-scrollbar {
  width: 10px;
}
&::-webkit-scrollbar-track {
  background: rgba(255, 255, 255, 0.1);
  border-radius: var(--radius-sm);
}
&::-webkit-scrollbar-thumb {
  background: var(--color-btn-blue-dark);
  border-radius: var(--radius-sm);
}
```

**Row Styling:**

- Background: panel gradient (white to cream)
- Border-radius: var(--radius-md)
- Box-shadow: var(--shadow-sm)
- Gap between rows: var(--spacing-sm)

**Accessibility:**

- tabindex="0" on scroll container
- role="list" on container
- role="listitem" on rows
- :focus-visible outline styling
