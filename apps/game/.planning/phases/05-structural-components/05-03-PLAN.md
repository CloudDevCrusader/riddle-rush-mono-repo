## Objective

Verify all three structural components (GameHeader, GameModal, GameScrollList) render correctly, match mockup styling, and have proper interactions.

## Context

This is a human verification checkpoint after the component implementation plans (05-01, 05-02) are complete.

Components to verify:

1. **GameHeader** - 3D text effects, color variants, slot layout
2. **GameModal** - Focus trap, backdrop, animations, header variants
3. **GameScrollList** - Scrolling, rank icons, row styling

## Tasks

<task id="1" type="human-verify">
<title>Visual and interaction verification</title>
<description>
Open the dev server and verify each component:

**GameHeader Checks:**

1. Open a page using GameHeader (or create a test route)
2. Verify 3D text shadow effect is visible and prominent
3. Test all 5 color variants: white, gold, green, blue, orange
4. Verify left slot renders (e.g., back button)
5. Verify right slot renders (even if empty, space reserved)
6. Check responsive behavior at different viewport widths

**GameModal Checks:**

1. Open a modal (e.g., existing QuitModal or PauseModal updated to use GameModal)
2. Verify modal appears centered with backdrop
3. Verify backdrop has ~55% opacity (can see background but dimmed)
4. Click backdrop - modal should close
5. Press Escape - modal should close
6. Tab through modal - focus should stay trapped inside
7. Verify open/close animation (scale + fade, ~250ms)
8. Test default variant (blue header) and danger variant (red header)

**GameScrollList Checks:**

1. Create a test with 6+ items to trigger scrolling
2. Verify custom scrollbar appears (blue thumb on light track)
3. Verify ranks 1-3 show crown icons (gold, silver, bronze)
4. Verify ranks 4-6 show numbered badges
5. Verify row styling (panel gradient background, shadows)
6. Test with 1-6 players - layout should not break

**Accessibility Checks:**

- Modal has role="dialog" and aria-modal="true"
- Modal header has aria-labelledby connection
- ScrollList container has role="list"
- Keyboard navigation works in all components
